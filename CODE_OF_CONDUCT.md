# Code of Conduct

EdgeHome Harness is a technical project about small-model command safety. Keep
discussion specific, evidence-based, and respectful.

Expected behavior:

- Explain technical claims with code, logs, configs, docs, or reproducible
  commands.
- Be precise about implemented scope versus future targets.
- Redact secrets, tokens, private URLs, and real device identifiers.
- Challenge designs directly, not people.
- Help keep the model-output boundary, fail-closed behavior, and safety policy
  understandable to reviewers.

Unacceptable behavior:

- Harassment, personal attacks, or discriminatory language.
- Posting private credentials, backend tokens, or exploit details in public
  issues.
- Misrepresenting prototype or dry-run behavior as production device support.
- Pressuring maintainers to weaken safety gates for convenience.

Maintainers may edit, hide, or close discussions that violate these rules.
